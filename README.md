# Memory Card

## Description:

### Game Overview

Memory Card is a simple game where you get points by selecting a unique picture everytime.

### The Goal

The player's goal is to remember the pictures they've already clicked, even though they keep moving around the screen.

### Score

You get 1 point for every unique picture you select

### Game Over

The game ends instantly if you accidentally click a picture you already selected before. You last high score will be saved.

## Features:

- User is given a grid of pictures to select from.
- Everytime a user selects a unique, correct picture, they are given a point of 1, the positions of the pictures are shuffled.
- If the user picks a picture already selected, they've lost, & have to start all over again.
- The user's best score is recorded.
