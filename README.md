# CV Project

## Description:

This is a small application where users can input their information and generate a CV/résumé.

## Features:

- Create CV button to allow users access the CV creation form.
- CV creation form allows users to input their details.
- Once a user is satisfied with their information, they can submit the form.
- A CV will be automatically generated from the information supplied.
- User can simply download the created CV.

## Tech Stack

- React JS
- HTML
- CSS
- JavaScript
- JSX
